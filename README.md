# Jiana Bullions LLP — Digital Business Card

A responsive GitHub Pages contact page for **Jiana Bullions LLP**, based on the supplied Jiana Bullions business card.

## Design direction

- Textured midnight-blue background in `assets/images/background-texture.png`
- Champagne-gold accents and blue linework matching the updated card
- White typography
- Diagonal blue line system
- Diagonal blue-and-gold panel linework in `assets/linework/`
- Responsive digital-business-card layout
- Mobile-first clickable contact actions

The physical business card is treated as the visual source of truth; the page is rebuilt as responsive HTML/CSS rather than using the card artwork as a single raster background.
